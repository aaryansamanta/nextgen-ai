# Contributing to NextGenAI

Thanks for your interest in contributing to the NextGenAI website and mission! 🚀

This repository hosts the source for [nextgenai.org](https://www.nextgenai.org), the home of our student-led AI education movement.

## Ways to Contribute

- 🐛 **Bug reports** — Found a broken link, layout issue, or typo? [Open an issue](../../issues/new/choose).
- ✨ **Feature ideas** — Suggestions for new pages, programs content, or site improvements are welcome.
- 🎨 **Design & content** — Copy edits, accessibility fixes, and visual polish for the `website/` pages.
- 🌍 **Translations** — Help us reach more students by localizing key pages.

## Development Setup

The site is a PHP-based static site (`website/`). To run it locally:

```bash
cd website
php -S localhost:8000
```

Then open `http://localhost:8000` in your browser.

## Submitting Changes

1. Fork the repo and create a branch: `git checkout -b feature/my-improvement`
2. Make your changes inside `website/` (or the relevant `docs/` file).
3. Test locally with the PHP built-in server.
4. Open a pull request describing what changed and why.

## Code Style

- Keep markup consistent with the existing Bootstrap-based templates in `website/`.
- Prefer semantic HTML and accessible color contrast.
- Optimize any new images before committing (`website/img/`).

## Questions?

Reach out any time at [contact@nextgenai.org](mailto:contact@nextgenai.org) — we'd love to have you join the movement!
